# Dataset

We used the **Digital Lifestyle Benchmark Dataset (2025)** for this project.

### Dataset Details

* **Source:** Hugging Face
* **Original Author:** Tarek Masryo
* **Records:** 3,500
* **Features:** 24
* **Format:** CSV
* **License:** CC BY 4.0

### What's included?

The dataset contains information about:

* Demographics
* Digital device usage
* Social media activity
* Sleep and physical activity
* Mental wellbeing indicators
* Productivity scores

### Dataset Source

The dataset can be accessed here:

https://huggingface.co/datasets/tarekmasryo/digital-lifestyle-benchmark-dataset
